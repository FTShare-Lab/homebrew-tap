# Homebrew Tap for Agent Claim Network

本仓库提供 Agent Claim Network（ACN）的 Homebrew Formula。

## 安装

```bash
brew install FTShare-Lab/tap/acn
```

该 Formula 会安装以下命令：

- `acn`
- `acn-router`
- `acn-maintainer`

支持的平台：

- macOS 11 及以上，Apple Silicon
- macOS 11 及以上，Intel
- Ubuntu 22.04，x86_64

## 升级

```bash
brew update
brew upgrade FTShare-Lab/tap/acn
```

## 卸载

```bash
brew uninstall acn
```
